# Віджет Marstek Venus для iPhone

Віджет для застосунку [Scriptable](https://apps.apple.com/app/scriptable/id1405459188): показує відсоток заряду, поточне навантаження і на скільки вистачить заряду. Дані беруться з хмари Marstek, тож працює і поза домом.

## Встановлення

1. Встановіть **Scriptable** з App Store.
2. Створіть у Scriptable новий скрипт з назвою `Marstek` і вставте в нього вміст файлу `Loader.js`. Завантажувач сам братиме найновішу версію віджета з GitHub, тож оновлювати нічого вручну не треба.
3. Відкрийте Scriptable, запустіть скрипт **Marstek** і введіть email та пароль від застосунку Marstek.
4. На головному екрані: утримуйте палець на порожньому місці → **+** → Scriptable → малий або середній віджет → утримуйте віджет → **Редагувати віджет** → Script: **Marstek**.

Віджет можна додати й на екран блокування (прямокутний).

## Налаштування

Блок `CONFIG` на початку `Marstek.js`:

| Параметр | Що означає |
| --- | --- |
| `capacityKwh` | Ємність однієї станції: Venus E — `5.12`, Venus C — `2.56` |
| `minSoc` | Відсоток, нижче якого станція не розряджається (резерв) |
| `deviceName` | Назва станції, якщо в акаунті їх кілька, а потрібна одна |
| `refreshMinutes` | Як часто просити iOS оновити віджет |

## Як рахується час

Хмара Marstek не передає потужність виходу Backup, тому віджет рахує навантаження сам — за швидкістю, з якою падає відсоток заряду (один відсоток Venus E — це близько 51 Вт·год). Такі цифри позначені знаком **≈**: це середнє навантаження за останній час, а не миттєве.

- Перша оцінка з'являється після того, як заряд упаде на 1–2%: при 200 Вт це 15–30 хвилин, при 1 кВт — кілька хвилин. До того замість цифр стоїть «—».
- Час роботи = `(заряд − minSoc) ÷ швидкість падіння заряду`.
- Якщо заряд зростає, показується час до повного заряду.
- Якщо заряд не змінюється понад дві години, віджет вважає, що навантаження немає.

## Що варто знати

- iOS сама вирішує, коли оновлювати віджети, зазвичай раз на 5–15 хвилин. Тап по віджету оновлює його одразу.
- Якщо після входу у віджеті вас викидає із застосунку Marstek, створіть другий акаунт Marstek, поділіться з ним станцією і введіть у скрипті його дані.
- Пароль зберігається лише в Keychain телефона як md5-хеш. Змінити акаунт: запустіть скрипт у Scriptable → «Змінити акаунт».
- Якщо хмара недоступна, віджет показує останні відомі дані зі знаком ⚠.
- API хмари неофіційний (той самий, що використовує інтеграція `marstek_cloud` для Home Assistant), Marstek може його змінити.
