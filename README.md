# Віджет Marstek Venus для iPhone

Віджет для застосунку [Scriptable](https://apps.apple.com/app/scriptable/id1405459188): показує відсоток заряду, навантаження і на скільки вистачить заряду. Дані беруться з хмари Marstek, тож працює і поза домом.

## Встановлення

1. Встановіть **Scriptable** з App Store.
2. Створіть у Scriptable новий скрипт з назвою `Marstek` і вставте в нього вміст файлу `Loader.js`.
3. Запустіть скрипт. Він попросить:
   - **код підпису** (16 символів) — один раз; без нього оновлення віджета не запускаються;
   - **email і пароль** від застосунку Marstek — вхід перевіряється одразу.
4. Додайте на головний екран віджет Scriptable (малий або середній) і виберіть у ньому скрипт **Marstek**.

Є також віджети для екрана блокування: прямокутний, круглий і рядковий.

## Як користуватися

- **Натискання на віджет** відкриває Scriptable і одразу показує свіжі дані.
- **Запуск скрипта в Scriptable** відкриває меню: показати малий або середній віджет, налаштування станції, зміна акаунта, діагностика.
- **Налаштування станції** (ємність, резерв, назва) зберігаються на телефоні. Резерв — це 100 мінус *Depth of Discharge* із застосунку Marstek; якщо зміните його там, змініть і тут.

## Що показує віджет

| На екрані | Що означає |
| --- | --- |
| `21:42` у куті | коли віджет востаннє отримав дані |
| `⚠ 21:42` | хмара зараз недоступна, показано збережені дані |
| `⚠ 11.11 21:42` і «Немає зв'язку з хмарою» | даних немає понад пів години, показано лише останній відомий заряд |
| `≈250 Вт`, `≈14 год` | оцінка за швидкістю зміни заряду |
| «Навантаження (уточнюю)», сірі цифри | оцінка ще груба, даних замало |
| `рахую…` | оцінки ще немає: заряд не встиг змінитися |
| `<60 Вт`, `≈0 Вт` | заряд давно не змінюється, навантаження менше за вказане |
| риска на смужці заряду | резерв: заряд лівіше від неї станція не віддає |

Колір заряду залежить від того, скільки лишилося понад резерв: зелений, помаранчевий (менше 30%), червоний (менше 10%).

## Як рахується навантаження і час

Хмара Marstek не передає потужність виходу Backup, тому віджет рахує навантаження сам — за швидкістю, з якою змінюється відсоток заряду (один відсоток Venus E — це близько 51 Вт·год).

- Оцінка з'являється після того, як заряд зміниться на 2%: при 200 Вт це близько пів години, при 1 кВт — кілька хвилин.
- Вона спирається на останні 2–3 відсотки, тому на зміну навантаження реагує за 20–40 хвилин.
- Час роботи = `(заряд − резерв) ÷ швидкість падіння заряду`.
- Якщо заряд зростає, показується час до повного заряду. Біля 100% заряджання сповільнюється, тож ця цифра приблизна.

## Оновлення віджета

- iOS сама вирішує, коли оновлювати віджети: зазвичай раз на 5–15 хвилин, інколи рідше. Оцінка працює й при оновленні раз на годину, але стає грубішою.
- Щоб замірів було більше, можна створити автоматизацію в застосунку Shortcuts: **Automation → App → Is Opened → Run Immediately → Scriptable: Run Script → Marstek** (Run In App вимкнено).
- Нові версії коду віджет бере з GitHub сам: перевіряє раз на пів години, а при запуску в Scriptable — одразу. Якщо нова версія не запускається, лишається попередня.

## Безпека

- Пароль зберігається лише в Keychain телефона як md5-хеш. Для хмари Marstek цей хеш рівноцінний паролю, тому безпечніше створити окремий акаунт Marstek, поділитися з ним станцією (*Share Device*) і вводити у віджет його дані.
- Код віджета лежить у публічному репозиторії, але телефон запускає лише версії, підписані кодом підпису. Код підпису зберігається на комп'ютері у файлі `.signing-key` (не потрапляє в git) і в Keychain телефона.
- API хмари неофіційний (той самий, що використовує інтеграція `marstek_cloud` для Home Assistant), Marstek може його змінити.
