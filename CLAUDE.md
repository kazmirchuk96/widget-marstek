# widget-marstek

Віджет iPhone для зарядної станції Marstek Venus E: відсоток заряду, поточне навантаження, на скільки годин вистачить заряду. Працює в застосунку Scriptable (JavaScript), не нативний застосунок.

## Файли

- `Marstek.js` — увесь віджет одним файлом. Саме його користувач копіює в iCloud Drive → Scriptable, тому він має лишатися самодостатнім: без імпортів, без збірки.
- `test/test.js` — тести для Node.
- `README.md` — інструкція зі встановлення для користувача.

## Перевірка

```bash
node test/test.js
```

Тест перевіряє MD5 проти `crypto`, розрахунок часу роботи та проганяє весь скрипт на заглушках Scriptable для малого, середнього віджета й екрана блокування. Запускай після кожної зміни `Marstek.js`. Справжній Scriptable і хмару Marstek звідси перевірити неможливо — кажи про це прямо.

## Заливка на iPhone

Користувач не розробник і файли вручну не переносить. `deploy.sh` проганяє тести й копіює `Marstek.js` у теку Scriptable в iCloud Drive (`~/Library/Mobile Documents/iCloud~dk~simonbs~Scriptable/Documents`), звідки файл сам синхронізується на iPhone. Хук `.git/hooks/post-commit` викликає `deploy.sh` після кожного коміту, тож коміт = заливка. Хук не зберігається в репозиторії: після клонування створи його заново (`#!/bin/sh` + `exec ./deploy.sh`, `chmod +x`). Після коміту перевір у виводі рядок `deploy:` і скажи користувачу, чи файл оновлено.

## Як влаштовано

- Дані — з неофіційного хмарного API Marstek (`eu.hamedata.com`): вхід `v2_get_device.php` (email + md5 пароля) дає токен, `getDeviceList` повертає станції з полями `soc`, `load`, `charge`, `discharge`, `report_time`. Джерело знань про API — інтеграція `DoctaShizzle/marstek_cloud` для Home Assistant.
- Scriptable не вміє UDP, тому локальний Open API станції (порт 30000) напряму недоступний.
- Облікові дані зберігаються лише в Keychain телефона (`marstek.email`, `marstek.pwdhash`, `marstek.token`). Ніколи не вписуй email, пароль чи токен у файли репозиторію.
- У кінці `Marstek.js` є гілка `typeof ListWidget === "undefined"`: поза Scriptable скрипт не запускає `main()`, а експортує чисті функції для тестів.
- Верхні три рядки-коментарі (`Variables used by Scriptable`) не чіпати — це метадані іконки.

## Параметри станції

Venus E: ємність 5,12 кВт·год, резерв (`minSoc`) 12%. Час роботи = ємність × (заряд − резерв) ÷ потужність розряду; якщо батарея не розряджається — ділимо на навантаження; під час заряджання показуємо час до повного заряду.
